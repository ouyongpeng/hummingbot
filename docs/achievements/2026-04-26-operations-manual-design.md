## 1. 需求概述

从 Hummingbot 官方文档站（https://hummingbot.org/docs/）抽取关键知识点，制作成一份**全面参考手册**，面向有一定基础的用户，系统整理所有模块的核心概念、配置项、命令参考，侧重知识查阅。

### 约束

- 覆盖官方文档全部 14 个章节
- 内容来源：官网文档为主，本地源码补充配置参数细节
- 输出格式：单文件长文档（Markdown）
- 语言：中文
- 不编写测试、不创建自动化脚本、不做国际化

## 5. 内容获取策略

```
官网文档（WebFetch）→ 提取核心知识点 → 本地源码（Read/Grep）补充配置参数 → 整合写入手册
```

1. **官网文档抓取**：按章节逐页抓取，提取核心概念、操作步骤、配置说明
2. **源码补充**：
   - 策略配置 → `hummingbot/strategy_v2/` 和 `controllers/` 目录下的 Config 数据类
   - 连接器配置 → `hummingbot/connector/` 目录下的连接器配置
   - 客户端命令 → `hummingbot/client/` 目录下的命令实现
3. **整合原则**：
   - 官网文档为权威来源，源码仅补充官网未覆盖的参数细节
   - 配置参数表标注来源（官网 / 源码）
   - 代码示例从源码中提取真实用法

## 6. 质量保障

1. **内容校验**：每个章节完成后，交叉验证官网文档与源码一致性
2. **链接验证**：确保手册中引用的命令、配置项在源码中真实存在
3. **版本标注**：手册开头注明基于的 Hummingbot 版本和文档抓取日期
4. **缺失标记**：官网文档未覆盖且源码中也未找到的信息，用 `[待补充]` 标记
5. **不涉及**：不编写测试、不创建自动化脚本、不做国际化
